# AB Lab

Платформа A/B-тестирования: детерминированное разделение пользователей по экспериментам, сбор событий, проверка статистической значимости результата.

## Быстрый старт

```
make install
make test
make run
```

*(команды появятся рабочими после того, как будет готов МВП — сейчас это ориентир для структуры проекта)*
