# Карточка проекта

| Поле | Значение |
|---|---|
| Рабочее название | AB-tect platform |
| Один тип пользователя | Человек, который тестирует гипотезу на своём продукте |
| Один основной сценарий | Создать эксперимент → получить вариант для пользователя → записать событие → посмотреть результат (конверсия по вариантам, на полной версии — статзначимость) |
| Чем результат проверяется автоматически | Набор тестов (`make test`): детерминированность бакетинга, соответствие распределения заданным весам, корректность расчёта конверсии; на полной версии — сверка формулы значимости с эталонной библиотекой (scipy) |
| Что уже работает на сегодня | Backend на FastAPI: создание эксперимента (с валидацией суммы весов), получение варианта (детерминированный бакетинг по sha256), запись событий, получение результатов (сырые цифры — users/conversions/conversion_rate). Хранилище — SQLite. Запускается тремя командами: `make install`, `make test`, `make run` |
| Сколько проверок в проекте сейчас | 1 (тест устойчивости бакетинга) |
