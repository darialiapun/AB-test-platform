# Карточка проекта

| Поле | Значение |
|---|---|
| Рабочее название | AB-test platform |
| Один тип пользователя | Человек, который тестирует гипотезу на своём продукте |
| Один основной сценарий | Создать эксперимент → получить вариант для пользователя → записать событие → посмотреть результат (конверсия по вариантам + статзначимость: z-test/точный тест Фишера по порогу малых выборок, Wald-доверительный интервал, поправка Бенджамини-Хохберга на множественные сравнения; опционально — проверка на sample ratio mismatch) |
| Чем результат проверяется автоматически | 29 тестов (28 в `make test`, плюс отдельный perf-тест через `make test-perf`): детерминированность бакетинга, соответствие распределения заданным весам, корректность расчёта конверсии, сверка формулы значимости с эталонными библиотеками (scipy/statsmodels), корректность хи-квадрат теста на sample ratio mismatch. Каждое поведение формализовано как EARS-требование (REQ-1..14) в `spec.md`, с Gherkin-критериями приёмки |
| Что уже работает на сегодня | Backend на FastAPI: создание эксперимента (валидация суммы весов = 100 и минимум 2 варианта), получение варианта (детерминированный бакетинг по sha256), запись событий, получение результатов — конверсия по вариантам + статзначимость (z-test/Фишер, Wald CI, BH-поправка), опциональная проверка sample ratio mismatch (`?check_srm=true`, хи-квадрат тест). Хранилище — SQLite. Запускается тремя командами: `make install`, `make test`, `make run` |
| Сколько проверок в проекте сейчас | 29 (28 в `make test` + 1 perf-тест отдельно через `make test-perf`) |
